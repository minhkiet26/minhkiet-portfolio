# Bàn giao Portfolio

Đọc [AGENTS.md](../../../AGENTS.md), [context](../../context.md), [workflow](../../workflow.md), và `.agents/local/handoff.md` nếu có. Đối chiếu Git status/HEAD thực tế; không dùng ghi chú cũ làm bằng chứng remote hiện tại.

Khi có mốc bàn giao hoặc được yêu cầu checkpoint, kiểm tra `.agents/local/` được ignore trước khi ghi `.agents/local/handoff.md`. Tóm tắt mục tiêu/phạm vi, quyết định, branch/HEAD, thay đổi cần giữ, đã làm/còn dở, file liên quan, lệnh kiểm tra/kết quả và bước tiếp theo. Tách rõ build, browser và deploy; ghi cảnh báo dependency còn mở.

Không chép transcript, dữ liệu liên hệ hoặc credential. Không tự cập nhật memory toàn cục. Khi không ghi được, bàn giao trong chat và nêu chưa lưu. Handoff không thay thế yêu cầu mới hoặc quyền phát hành.
