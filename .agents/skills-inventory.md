# Skill của Portfolio

| Skill | Khi dùng |
| --- | --- |
| [portfolio-ui](skills/portfolio-ui/SKILL.md) | Sửa giao diện song ngữ, theme, Dock, Swarm hoặc dialog của portfolio này. |
| [portfolio-handoff](skills/portfolio-handoff/SKILL.md) | Tiếp tục, checkpoint hoặc bàn giao task giữa các phiên. |

Skill nằm tại `.agents/skills/`. Đây là workflow tái sử dụng, không phải agent tự chạy. Context/workflow/coding-style là tài liệu chung được dẫn đọc.
